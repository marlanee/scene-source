동일한 모델·질문·공통 지침으로 RAG 사용 전후를 비교하고, 원문을 보고 직접 평가하세요.

실험 질문 선택

질문당 답변 생성 2회가 발생합니다. 실패 시 완료한 응답은 보존하며 다시 이어서 실행할 수 있습니다.

사람 평가 기준 · 각 0–2점

정확성: 중요한 사실 오류 → 부분 정확 → 정확한 답변
근거 지지: 불일치·가짜 → 일부 지지 → 주요 주장 지지
불확실성 처리: 없는 사실 단정 → 모호 → 확인 범위와 한계를 적절히 설명

미평가는 0점으로 계산하지 않습니다. 인용 번호의 존재만으로 사실 정확성을 판정하지 않습니다.
